# 模板开发的问题

模板开发中缺少路由使用和模板控制器的文档篇章

## 路由使用 

1. 参考示例项目，通过 App.php 中注册web路由， web 路由是可以通过浏览器直接浏览的
2. 路由的注册
3. 请求处理和响应，响应直接用 sendText 或者 sendTpl 来输出模板
3. 响应直接展示响应的格式即可 
4. 请求和响应的主要内容用过在模板控制器中编写
